**협업 페이지**: https://app.notion.com/p/B2-3-AI-3a82f355a7e281c2ae92d3cd8764c2ff

미션 요구사항 §2-2 의 "협업 도구 내 **프로젝트 개요 · 팀 구성원 역할 · 개인별 작업 요약** 포함" 을
이 페이지가 담고 있고, 그 아래에 결과물 DB(`소셜 콘텐츠`)가 연결돼 있다.

| DB 에 저장된 것 | 행 수 |
|---|---|
| 사람이 프롬프트를 다듬어 만든 최종본 (인스타 / 블로그 / X) | 3 |
| 보너스1 A/B 테스트 2버전 (A-친근 / B-전문) | 2 |
| **Make 시나리오가 자동 실행으로 만든 결과** (인스타 / 블로그 / X) | 3 |

속성 8개(제목·주제·플랫폼·콘텐츠·이미지·생성일시·글자수·톤)와 각 타입을 고른 이유는
루트 [`README.md`](../../README.md) §6 에 있다. 구축은 전부 Notion REST API 로 했다.
